# Operations Runbook

## Routine checks
- Review host and service health.
- Review backup job results and capacity thresholds.
- Review security updates and relevant alerts.
- Confirm monitoring and alert delivery are functioning.

## Change procedure
1. Describe the change, impact, and rollback plan.
2. Verify backups or snapshots where appropriate.
3. Apply the change during an approved window.
4. Run health checks and validate expected behavior.
5. Record outcome and update relevant documentation.
